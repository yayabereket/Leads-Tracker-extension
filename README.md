# Leads Tracker 
  Chrome Extension A simple, custom-built Chrome Extension that allows you to save the URLs of your current tabs. 
 ## Features 
  - Save the current tab URL with a single click. 
  - Manually type and save custom links.
  - Data is saved permanently using `localStorage` (persists even after browser restart).
  -  Double-click the "Delete All" button to clear your list.
  -  Links open in a new tab.
 ## How to Install and Test 
  1. Clone this repository to your local machine.
  2. Open Chrome and go to `chrome://extensions`.
  3. Turn on **Developer mode** (top right corner).
  4. Click **Load unpacked** and select the folder containing these files.
  5. The extension is now ready to use!
